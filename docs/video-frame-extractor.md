# 本地 AI Work 尾帧提取

尾帧接口处理已经完成的任务，不提交视频，不新增预算。需要专用桥接凭据及精确 request/budget/Key/account/execution/result 绑定。普通客户端无需安装提帧程序。

在 AI Work 数据目录放置 `video-frame-extractor.json`：

```json
{"path":"E:/AIWORK/tools/ffmpeg/ffmpeg.exe","sha256":"填写该可信固定版本可执行文件的完整 SHA256"}
```

仅允许本地绝对路径；每次使用验证摘要。版本更新后重新计算摘要，不能以任意 PATH 程序或客户端参数代替。程序必须支持本地 MP4 解码、PNG 编码、showinfo 和 image2。缺失配置或不支持源视频编码时只报告提帧不可用，不重生成原视频，不影响普通生成、下载和积分结算。

当前本机验证的已安装程序为 SteelSeries 附带 FFmpeg（gg-93.0.0-22730-g8ecf29decd），摘要 `ff8d9e4fb41c9563022e2e3d4fc040130efb31595959bfc6613f1ae52f039d31`；支持 H264/MJPEG 到 PNG，未验证其他源编码。不可把此摘要用于其他版本。

2026-09-29 已在本机持久数据目录安装可信提帧配置，并运行发布包 `20260929-work-context-4133b37`。真实灰度 V2 提取864×496、timestamp5000ms的PNG，来源MP4摘要与实际客户端下载文件一致。Core 的真实HTTP传输必须保留长度及所有来源校验头；仅假传输测试不足以验证此契约。

非正常重启若出现 `recovery_required`，先检查同机单活动实例，再按[单机恢复流程](bridge-budget-recovery.md)显式确认保留旧未知占用。不要删除数据库或关闭费用核对来恢复派发。

固定参数、不经过 shell，输入协议仅 file/pipe；只解码末尾两秒。进程超时30秒，输出最多8MiB，并发2、等待队列8。来源和尾帧分别保存 SHA256、像素尺寸和最后可解码帧时间。按来源摘要及算法版本复用私有缓存。源文件持有有期限的磁盘租约，崩溃租约过期后可恢复清理。

测试须先从测试进程环境中移除 `AIWORK_VIDEO_DIR`，不得将夹具写入正式视频目录。本机合成1秒/8fps夹具的最后一帧时间为875ms。生产能力是否开放仍取决于独立的续写契约验收，提帧成功不等于原生视频延长已获支持。
