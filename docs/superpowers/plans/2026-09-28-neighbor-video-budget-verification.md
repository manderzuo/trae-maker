# 未知规格预占与真实回执校准

## 本轮规则

- 预占不是最终扣费，不再因为缺少精确秒数政策而无条件拒绝：使用同模型、清晰度及素材类别的有效邻近时长。优先不短于目标的最近档；没有较长档时按最长已知档的时长比例向上外推。
- 480p/720p 的画幅仅参与实际生成，不拆成不同价格档。图片数量、参考视频数量及参考视频秒数仍隔离，不用无参考视频的价格承诺参考视频费用。
- 持久化的已准备请求和最终回执就是校准依据，不新增第二份账本。相同执行账号、精确规格的近期成功正费用记录优先用于下次预算，采用最近七天样本的最高值并加 10% 余量、向上取整到一积分。
- 没有精确记录时先尝试现有原生估算或有效政策（包含邻近政策）；二者缺失时允许邻近真实记录作风险预占。没有任何同类别依据仍明确拒绝，而不是冻结全部 Key 余额或编造费用。
- 最终按可信回执精确结算，预估费用不写成真实消费。回执变为冲突后立即排除该样本；失败、未知及零费用不学习。历史账本长期保留，七天限制只影响是否作为当前价格依据。

## 实际验证

Windows 上使用离线 Cargo 完整回归：748 项通过、0 失败、8 项跳过。新增覆盖包括邻近较长档、无较长档外推、素材类别隔离、重启后复用真实最终费用和冲突样本排除。已有画幅规范化测试同时验证生成参数仍保留用户画幅。

测试使用独立的 Windows 主机租约命名空间，仍保留互斥契约；生产租约名称和保护不变。执行测试的子进程清除了继承的生产素材/视频/数据路径覆盖，临时文件位于 D 盘专用目录。未关闭生产 AI Work。

本轮没有提交新的付费上游任务，也没有部署公网或重启本机生产程序；这是本地代码与隔离回归验证，不代表新版本客户端真实素材生成验收已完成。

## 自审与限制

检查了预算算术上溢、规格和账号隔离、真实回执身份绑定、容量预占 CAS 和未知费用保留机制。未新增无证据退款或重复付费重试。校准只是风险估计，不是上游官方固定价；实际费用超过预占时仍按真实费用处理，不截断成预估值。

本轮没有修改 DSH 下载工具诊断、长聊天输入 413、观察者竞争 429 或 MCP 的通用 503 错误呈现。Core 的素材续接改动在独立 Trae-core 仓库。
